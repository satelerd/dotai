# manifest.txt — defines what gets synced between $HOME and this repo
#
# Format (3 columns, space-separated):
#   MODE        HOME_PATH (relative to $HOME)        REPO_PATH (relative to repo root)
#
# MODE:
#   sync      -> direct copy in both directions (file or directory).
#               push: HOME -> repo (mirror, with --delete on dirs).
#               pull: repo -> HOME (additive, NEVER deletes local files).
#   sanitize  -> file containing secrets. push: redacts and saves as template.
#               pull: does NOT overwrite the real file; writes <file>.from-sync instead.
#
# Lines starting with # are comments. Missing paths are skipped with a warning.
